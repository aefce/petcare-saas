# 🏨 PetCare SaaS 寵物旅館與美容預約管理系統

這是一個為現代寵物旅館與寵物美容店設計的 B2B2C 雲端 SaaS 平台。系統整合了客戶預約、實體旅館房態管理、美容服務、打卡考勤系統、以及多層級權限控制，旨在提升店內營運效率並提供顧客良好的數位服務體驗。

---

## 🌟 核心功能特色

### 1. 角色分工與權限控制
本系統採用精細的角色權限架構 (Role-Based Access Control)，不同角色登入後將看見專屬的工作儀表板：
- **一般飼主 (Customer)**: 可管理多隻寵物的檔案（包含照片上傳、疫苗證明提交），並可線上發起美容與寵物旅館的預約。同時可以申請預約退費。
- **櫃檯人員 (Receptionist)**: 專注於前台接待。可檢視「今日預計入住/退房」名單、管理旅館房態（調整清潔中/維修中），以及分配寵物的負責照護員。
- **照護員 (Caretaker)**: 專注於「只指派給我的寵物」。可快速撰寫每日照護日誌（支援上傳萌照）、記錄情緒與食慾，並處理房間清潔工作。
- **美容師 (Groomer)**: 專注於美容任務清單。完成服務後一鍵「標記完成」，系統會自動推播通知給櫃檯與照護員來接手寵物。
- **店長/管理員 (Admin)**: 擁有最高權限。可管理服務項目、房型庫存、檢視員工打卡紀錄、查閱營業報表，以及進行「退費審核」。

### 2. 多型退費審核機制 (Polymorphic Refund Flow)
支援一般美容預約與旅館預約的退費申請。顧客提出退費理由後，需由店長在專屬的「退費審核面板」進行人工審核，並能輸入拒絕或批准原因，財務紀錄清晰可查。

### 3. 實體房間與庫存管理
跳脫單純的數量控管，系統支援建立「實體房號 (例如：A01, B02)」。櫃檯可將房間設為「維護中」，系統將自動從可用庫存中扣除該房位，避免超賣。

### 4. 系統通知中心 (Notification Center)
內建全域系統通知，當美容師完成服務、照護員提報寵物異常、或出現退款申請時，相關負責人（如資深照護員、店長）會立即收到推播通知（UI 右上角小鈴鐺），增進跨部門協作效率。

## 🚀 技術架構

- **前端 (Frontend)**: React 18 + TypeScript + Vite + TailwindCSS + Framer Motion + Zustand
- **後端 (Backend)**: FastAPI (Python) + SQLAlchemy + PostgreSQL + Redis (用於預約庫存 Mutex 鎖定與 TTL)
- **環境容器化**: Docker & Docker Compose

## 🛠️ 環境配置與啟動指南

### 1. 啟動資料庫與 Redis (Docker)
在專案根目錄下，啟動所有相依服務：
```bash
docker-compose up -d
```

### 2. 啟動後端服務 (Backend)
進入 `backend` 目錄並啟動虛擬環境：
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # Windows
# source venv/bin/activate # Mac/Linux
pip install -r requirements.txt
```

執行資料庫遷移與假資料填充：
```bash
alembic upgrade head
python seed.py
```

啟動 FastAPI 開發伺服器：
```bash
uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
```

### 3. 啟動前端應用程式 (Frontend)
開啟另一個終端機，進入 `frontend` 目錄：
```bash
cd frontend
npm install
npm run dev
```

瀏覽器開啟 `http://localhost:5173` 即可訪問平台。
